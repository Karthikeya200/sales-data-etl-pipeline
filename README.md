# Sales Data ETL Pipeline

##  Project Overview

This project demonstrates an end-to-end ETL (Extract, Transform, Load) pipeline built using Python, Pandas, and SQLite.

The pipeline processes sales data, performs data transformation, loads the processed data into a SQL database, and performs business analysis using SQL queries.

---

##  Technologies Used

- Python
- Pandas
- NumPy
- SQLite
- SQL
- Google Colab

---

##  ETL Process

### 1. Extract

Sales data is loaded into a Pandas DataFrame.

### 2. Transform

The data is processed by:

- Checking for missing values
- Calculating total sales
- Standardizing column names
- Preparing the dataset for database storage

### 3. Load

The transformed data is loaded into a SQLite database using Python.

---

##  SQL Analysis

The following analysis was performed:

- Total revenue calculation
- Product-wise sales analysis
- Quantity sold by product
- Revenue generated by each product
